PC에서 플레이하기
ZIP의 모든 파일을 같은 폴더에 풀고 index.html을 Chrome 또는 Edge에서 엽니다.
처음부터를 누르면 음악이 시작됩니다. 이어하기는 이 브라우저에 저장된 진행 기록을 사용합니다.

조작
클릭, 터치, Enter, Space — 대사 표시 및 다음 대사
Ctrl — 읽은 대사 빠르게 넘기기
Esc — 설정 열기 또는 메뉴 닫기
SAVE / LOAD — 수동 저장 슬롯 3개와 자동 저장
AUTO / SKIP / LOG — 자동 진행, 스킵, 대화 기록

엔딩을 본 뒤 직전 선택지로 돌아갈 수 있습니다.
타이틀의 엔딩 컬렉션과 CG 갤러리에서 발견한 콘텐츠를 다시 볼 수 있습니다.
웹에서 공유할 때는 풀어 둔 폴더 전체를 정적 웹 호스팅에 올리면 됩니다.
